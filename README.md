# ZYNQ-7020 嵌入式开发完全教程

> 从入门到软PLC实战 —— 一条经过验证的学习路线，覆盖 Xilinx ZYNQ SoC 的 PS（ARM）与 PL（FPGA）双侧开发。

本项目为**单文件离线网页**形式的中文交互式课程，基于 **正点原子 · 领航者ZYNQ 开发板（XC7Z020-CLG484）** 编写，配套工具链为 **Vivado / Vitis / PetaLinux 2020.2**。打开 `index.html` 即可学习，无需任何网络环境。

## 课程亮点

- 🧩 **芯片**：XC7Z020（Zynq-7000，双核 ARM Cortex-A9 + Artix-7 级 FPGA）
- 🚀 **开发板**：正点原子 · 领航者ZYNQ
- 🛠️ **工具链**：Vivado / Vitis / PetaLinux 2020.2（全链路版本统一）
- 🐧 **系统**：Linux 5.4 + 设备树 + 内核驱动开发
- 🏭 **终极项目**：工业级软PLC（梯形图解释器 + Modbus TCP/RTU + Web 监控）
- ✅ **9 大篇章 + 51 章 + 附录面试题库（92 题）**，由浅入深、全程可动手

## 课程目录

### 第一篇 · 基础知识篇（第 1~10 章）

ZYNQ 架构、开发板硬件资源、开发环境搭建、Verilog HDL 快速入门、纯 PL 流水灯工程、PS 裸机开发（Hello ZYNQ）、PS 外设编程（GPIO/UART/中断/定时器）、AXI 总线与自定义 IP 设计、PS+PL 协同设计综合实验。

### 第二篇 · 嵌入式Linux篇（第 11~20 章）

嵌入式 Linux 开发环境准备、启动流程深度剖析、U-Boot 编译移植与 BOOT.BIN 制作、内核编译与设备树基础、PetaLinux 全流程实战、根文件系统与 BusyBox、字符设备驱动开发、设备树进阶与 platform 驱动、常用外设驱动（UART/SPI/I2C/IIO）、Linux 应用编程。

### 第三篇 · 调试验证篇（第 21~25 章）

ILA/VIO 在线逻辑调试、时序分析与时序收敛、JTAG 裸机调试、Linux 应用远程调试（GDB + VSCode）、内核调试与软硬件联合验证方法论。

### 第四篇 · 软PLC实战篇（第 26~36 章）

项目需求分析与总体架构 → PL 侧 IO 引擎设计 → Linux 平台定制与 UIO 驱动 → 软PLC 运行时内核设计 → 梯形图解释器实现 → 功能块（定时器/计数器）→ Modbus TCP/RTU 从站实现 → Web 监控界面 → 系统集成与开机自启 → 综合案例与验收测试 → 项目总结与技术展望。

### 第五篇 · 进阶精通篇（第 37~42 章）

内核并发与同步专题、AXI-DMA 高速数据通路实战、性能剖析（ftrace/perf/kmemleak）、AMP 双核开发（OpenAMP/rpmsg）、扩展实战项目集（4 选 2）、能力矩阵与成长闭环。

### 第六篇 · 工业自动化专题（第 43~47 章）

PLC 硬件模块研发设计、标准体系与功能安全认证（IEC 61508 / SIL）、工业总线与工业以太网全景、冗余设计与高可用架构、网络抓包解析与排故实战。

### 第七篇 · 嵌入式RTOS专题（第 48~50 章）

FreeRTOS 源码框架解析、FreeRTOS 移植部署与调试、SeL4 微内核解析与实践。

### 第八篇 · Linux系统优化（第 51 章）

性能术语精确定义、CPU/内存/IO/网络/启动五维优化手段、工具箱全景、实战案例与分析决策树。

### 附录 · 面试题库

- **附录 A**：数电 / Verilog / ZYNQ / 工业专项
- **附录 B**：C / Linux / 驱动 / RTOS 专项
- **附录 C**：项目深挖 / 系统设计 / 行为面
- **附录 D**：工业自动化术语速查表（PLC 五大语言、IEC 61508 功能安全、总线协议、TSN、EMC 等）

## 环境要求

| 软件 | 版本 | 安装位置 |
|------|------|----------|
| Vivado + Vitis | 2020.2（含 Zynq-7000 器件支持包） | Windows 10/11 或 Ubuntu 虚拟机 |
| PetaLinux | 2020.2 | 仅支持 Linux 主机（推荐 Ubuntu 18.04 虚拟机，磁盘 ≥150GB，内存 ≥16GB） |
| 交叉编译器 | arm-linux-gnueabihf-gcc（PetaLinux SDK 自带） | Ubuntu 虚拟机 |
| VSCode + Remote 插件 | 最新版 | Windows 宿主机 |
| 串口终端 | MobaXterm / PuTTY / minicom | 宿主机 |

> ⚠️ **版本一致性铁律**：Vivado / Vitis / PetaLinux 三者必须使用同一版本（本课程统一为 2020.2），混用会导致 FSBL、设备树、内核驱动不匹配等难以排查的问题。
